# S5_13 — Git Flow e versionamento colaborativo

**Situação.** Política, histórico e changelog entregues; release e proteção não aplicadas.

Adotar GitHub Flow: branch curta por mudança, PR pequeno, CI verde e integração em main. Para equipe reduzida, reduz custo de manter branches de longa duração. Em correção urgente, criar branch de hotfix a partir da versão afetada e revisar o PR.

Ver CHANGELOG.md e os commits oficiais citados. A tag v1.0.0, release e proteção da branch são operações no GitHub que dependem da publicação autorizada; o pacote contém notas de release prontas.
