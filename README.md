# Entregáveis — Inventário de Ativos e Vulnerabilidades

Repositório acadêmico que reúne os entregáveis individuais das Sprints 1 a 4 do projeto de Inventário de Ativos e Vulnerabilidades.

## Organização

- Sprint-1/: entregáveis dos cards S1_01 a S1_20 e o mapa de evolução.
- Sprint-2/: entregáveis dos cards S2_01 a S2_19.
- Sprint-3/: entregáveis dos cards S3_01 a S3_20.
- Sprint-4/: entregáveis dos cards S4_01 a S4_20, com PDFs, fontes e evidências.

Cada card possui seu PDF e sua fonte LaTeX. Os cards que pedem programação também possuem os respectivos arquivos Python. Algumas entregas incluem imagens de verificação, quando elas fazem parte da evidência.

## Conteúdo

- 80 documentos PDF;
- fontes LaTeX correspondentes;
- scripts Python, SQL e documentos de evidência quando o card pede exemplo;
- arquivos de preparação de Docker e servidor sem execução nesta etapa.

Arquivos temporários de compilação, logs e caches de Python foram propositalmente excluídos.
