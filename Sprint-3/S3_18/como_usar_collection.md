# S3_18 — coleção Postman

O arquivo postman_collection.json contém duas requisições:

1. GET /ativos, para listar os registros;
2. POST /ativos, para cadastrar um ativo de exemplo.

Para executar no Postman:

1. iniciar a API com python api.py dentro da pasta S3_19;
2. abrir o Postman e escolher Import;
3. selecionar postman_collection.json;
4. executar GET e POST e conferir os códigos 200 e 201.

A estrutura JSON da coleção foi validada localmente. A execução dentro do aplicativo
Postman fica pendente porque ele não está instalado neste computador.
