# Sprint 3

Cada pasta S3_XX contém o PDF e o fonte LaTeX do card. Quando o card exige
programação, a mesma pasta também guarda o código executável.

O repositório principal guarda somente o Inventário de Ativos e sua automação
de testes. Este repositório guarda relatórios, exemplos e demais evidências.

As evidências externas foram verificadas e registradas: GitHub Actions verde na
S3_08, protótipo editável no Figma na S3_15 e collection Postman executada pelo
Newman na S3_18. Cada pasta correspondente contém o material e a evidência.

S3_09 e S3_12 também confrontam os exemplos da aula **Álgebra Linear para
Análise de Risco** enviada pelo docente: CVE compartilhada entre dois ativos,
coluna nula ilustrativa, sistema linear e condicionamento numérico. O fator de
exposição `F` é apresentado como extensão, sem alterar arbitrariamente os pesos
do inventário principal.
